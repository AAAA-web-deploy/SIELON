# SIELON complete rebuild kit

Extract the ZIP, open this folder in Cursor, and paste the entire CURSOR_BUILD_PROMPT.md into Cursor Agent.

Everything needed is included: all approved photographs and branding, the corrected notebook scene, three reaction images, an SI portrait texture, the original particle-engine source, local Three.js with its license, complete story copy, configuration, and dependency-free preview/build tools.

The supplied site is the prior mobile/static baseline. Cursor rebuilds the desktop Home and Story pages from the new prompt and integrates the particle engine; the baseline is not presented as the completed redesign. No extra assets, API keys, or dependency installation are required.

Preview after Cursor's changes: `node tools/serve.mjs`. Build: `node tools/build.mjs`. Validate supplied inputs: `node tools/verify.mjs`.
