# Quantum Inu reference, checked October 14, 2026

Reference: https://quantuminuhub.com/

Its published implementation uses Three.js, a portrait texture, roughly 20,000 desktop points, pointer-driven spring displacement, press/release splitting, sampled-shape morphs, collapse into a surviving point, and reformation. A sticky scroll stage changes the scene's state. Photographic planes retain recognition while the particle forms move. This is an image-based particle sculpture, not a rigged dog model.

Observed directly: the dark poster composition, large overlapping title, portrait fallback, navigation, and disabled hold control. The inspection browser reported WebGL context creation disabled, so the live shader animation could not be visually exercised. The mechanisms above were checked in the published page code, not claimed as a completed visual animation audit.

Published implementation sources inspected:

- https://quantuminuhub.com/assets/universe-DHWyHLSA.js

SIELON translates those mechanisms into human/SI portraits, mechanical-wrist particles, two-face separation, and reformation. Its cinematic photo story, warm lighting, Ethereum identity and two desktop routes remain distinct. No reference-site artwork or implementation code is included. The supplied SIELON engine is original; Three.js is from its official MIT-licensed npm package.
